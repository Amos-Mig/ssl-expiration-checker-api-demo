What's inside

LIVE ABOVEBulk domain checks

One line per host: days-until-expiry, issuing CA, handshake latency. Paste your own list and run it.

LIVE ABOVEConfigurable thresholds

--warn 14 flags anything under 14 days. Change the number and re-run — statuses re-classify instantly.

LIVE ABOVECron-ready exit codes

0 = healthy, 1 = warning, 2 = critical. Schedule it blindly — no output parsing needed.

🔒 Chain & hostname validation

Full intermediate-chain verification, SNI matching and self-signed detection on every host — in the full script.

🔒 Alert integrations

Slack, SMTP and webhook alerts on state change, plus JSON/CSV reports and per-port checks — in the full kit.
